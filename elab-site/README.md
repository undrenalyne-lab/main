# Undrenalyn eLab public website

Static bilingual storefront. Edit content.json/template.html, then run `python3 elab-site/build.py` from the repository root. Generated pages: index.html and en/index.html. Assets are namespaced here; legal pages, other routes, Backchannel Atlas and Pages workflow remain independent.

Release: 2026-10-03-redesign-aea8902. No new runtime dependency.
